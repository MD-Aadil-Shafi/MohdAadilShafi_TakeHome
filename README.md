# MohdAadilShafi TakeHome

This repository contains a take-home implementation of a Figma-like **Canvas Comment** feature for Excalidraw.

- **Problem Statement & Rubric:** [`MohdAadilShafi_Solution/task/`](MohdAadilShafi_Solution/task/)
- **Solution:** [`MohdAadilShafi_Solution/`](MohdAadilShafi_Solution/)
- **Report:** [`MohdAadilShafi_Report.md`](MohdAadilShafi_Report.md)

---

## Running the Solution

All commands must be run from inside the solution directory:

```bash
cd MohdAadilShafi_Solution
```

### 1. Install dependencies

```bash
yarn
```

### 2. Start the development server

```bash
yarn start
```

The app will be available at `http://localhost:3001`.
